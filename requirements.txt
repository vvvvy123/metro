# Metro Transfer — dependencies
#
# LOCAL DEVELOPMENT NEEDS NOTHING FROM THIS FILE.
# With no DATABASE_URL set, the app runs on SQLite using only the standard
# library (http.server, sqlite3, json) — `python server.py` and you are done.
# Requires Python 3.8+.
#
# The single entry below is needed ONLY when DATABASE_URL is set, i.e. when
# running against Postgres (deployment). db.py imports psycopg lazily inside the
# Postgres branch precisely so the SQLite path stays dependency-free.
#
# [binary] ships a prebuilt libpq wheel, so no local Postgres client or compiler
# is required — that is what makes it installable in a Vercel build.
psycopg[binary]>=3.2
